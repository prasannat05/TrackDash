# TrackDash: Endless Runner

TrackDash is a browser-based endless runner game developed using HTML5 Canvas, JavaScript, and CSS. The player dodges obstacles, collects coins, and tries to achieve the highest score. The game is responsive, works on both desktop and mobile devices, and includes features like power-ups, a coin-based shop, combo multipliers, and integrated audio.

## Features

- Endless runner gameplay with increasing speed and difficulty.
- Coin collection system with a counter.
- Power-ups including shield and magnet.
- Smooth lane movement for the player character.
- Combo multipliers for scoring.
- Responsive design with keyboard controls for desktop and swipe gestures for mobile.
- Background music and sound effects with a mute toggle.
- High score and unlocked skins saved using local storage.
- Shop system for purchasing skins using collected coins.

## Controls

**Desktop:**
- Arrow Left / A – Move left
- Arrow Right / D – Move right

**Mobile:**
- Swipe Left – Move left
- Swipe Right – Move right
